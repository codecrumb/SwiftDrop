Allowing SwiftDrop to open new tabs
SwiftDrop · swiftdrop.pages.dev

Some browsers block websites from automatically opening new tabs or windows as a security precaution.

SwiftDrop uses this to instantly open URLs sent from another device. You can always click Retry in the prompt to open the link manually — but if you want it to open automatically every time, allow pop-ups for SwiftDrop in your browser settings.

How to allow pop-ups

  1. Click the icon in your address bar (usually a blocked pop-up icon, or the site settings/padlock icon).
  2. Find "Pop-ups and redirects" or "Always allow pop-ups from this site."
  3. Set it to Allow and reload the page if prompted.

Modal backdrop

The modal will sit on top of a semi-transparent overlay (rgba(0,0,0,0.5)) that covers the whole page — so it reads as a true blocking dialog, not a toast.

Detection strategy

Drop noopener from window.open(). Check return value — null means blocked, show modal. Non-null means tab opened, show nothing. Retry click = user gesture = always succeeds.
